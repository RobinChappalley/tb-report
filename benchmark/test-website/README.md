# Cloudinary React playground

Ce dossier contient un petit projet Vite React pour tester `AdvancedImage` de Cloudinary.

## Lancer le test

```bash
cd benchmark
npm install
npm run dev
```

## Ce que vous pouvez observer

- le rendu du composant `AdvancedImage`
- le comportement des plugins `lazyload()`, `responsive()`, `accessibility()` et `placeholder()`
- l’URL générée par `@cloudinary/url-gen`
- l’effet des changements de `cloudName` et `publicId`
